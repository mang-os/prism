# Contributing

Read [the build specification](PRISM_BUILD_SPEC.md) and [status](docs/build-status.md) before changing behavior. Preserve on-disk format/version rules and query semantics; document deliberate deviations. Add a focused invariant or integration check for storage/query changes. Run pytest, Ruff check/format, and mypy. Supply actual inputs, hardware, and outputs for performance or relevance claims. Keep downloaded models, corpora, credentials, and runtime indexes out of commits.
